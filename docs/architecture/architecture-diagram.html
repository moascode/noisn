Camunda 8.8+ · AWS Bedrock eu-west-1 · June 2026
WebSocket over polling Replaces 2-second REST polling. Push delivery eliminates latency and unnecessary load. Bidirectional — UI both receives agent messages and sends user replies over the same connection.
AI Agent Connector (job worker variant) The agenticai-aiagent-job-worker element template handles the LLM → tool-call → result → LLM loop natively inside Zeebe. Replaces ~300 lines of custom Python orchestration. Job worker variant required for non-interrupting event support.
Session Broker as the message router Single new component. Maps sessionId → processInstanceKey. Job workers call POST /send — no direct WebSocket knowledge. Decouples workers from transport.
Send-and-wait pattern send-to-ui worker pushes message and completes job immediately. BPMN advances to a non-interrupting Message Receive Event. User reply arrives via WebSocket → Broker calls publishMessage() → Zeebe correlates → agent loop resumes with new user input.
Workers are pure tool implementations No LLM logic in workers. prompts.py and invoke_llm() deleted. Workers only execute tool actions and return results via toolCallResult. Simpler, easier to test independently.
Calculator API unchanged api/ service requires zero modifications. All pension math, eligibility rules, and product defaults remain as-is.
